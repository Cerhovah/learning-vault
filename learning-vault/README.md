## 분류 규칙

1. **대분류:** `08_8월과정`부터 `12_12월과정`까지 시간순으로 정렬합니다.
2. **날짜:** 각 과정 안에 `YYYY-MM-DD_주제` 폴더를 만들고, 날짜를 모르면 `00_날짜미지정`에 둡니다.
3. **소분류:** 날짜 폴더 안에서 `01_E1_터미널_Docker_Git`, `02_E2_파이썬_JSON`, `03_E3_MAC_성능측정` 순으로 과목을 정렬합니다.
4. **과목 검색:** [과목별 찾아보기](90_과목별찾기/README.md)에서 날짜를 건너뛰고 과목별 자료를 찾습니다.

## 새 자료를 넣는 방법

날짜를 아는 경우:

~~~text
08_8월과정/
└── 2026-08-04_코디세이/
    ├── 01_E1_터미널_Docker_Git/
    ├── 02_E2_파이썬_JSON/
    └── 03_E3_MAC_성능측정/
~~~

날짜를 모르는 경우에는 해당 월의 `00_날짜미지정`을 사용합니다. 파일명은 `YYYY-MM-DD_주제.md`를 권장합니다.

기존의 `00_INBOX`, `10_CONCEPTS`, `20_PROJECTS` 같은 숫자형 분류는 제거하고, 기존 자료와 템플릿은 새 날짜·과목 구조 안으로 옮겼습니다.
